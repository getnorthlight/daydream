# Citing DayDream moments

The person should be able to find each thing you mention again, in DayDream or in their own apps. Cite in plain words, never with ids or links.

## Format

`(<when>, <app>: <window, document or site>)`

- **when**: use the reply's wording, such as "Today, 9:12 AM", "Yesterday afternoon" or "Tue 3:12 PM". In a recap, a block anchor like "Morning" is enough.
- **app**: the app name as the reply gives it (Zed, Mail, Chrome). Never a bundle id.
- **what**: the window or document title, or the site, shortened if long. Leave it out if the reply has none.

Examples:

- "You last had SyncEngine.swift open yesterday evening (Yesterday, 7:41 PM, Zed: SyncEngine.swift)."
- "You drafted a reply to Priya but didn't send it (Today, 9:10 AM, Mail: Re: launch)."
- "You texted Sam that you'd meet at noon (Today, 9:00 AM, Messages, sent)."

## Rules

- Cite what the action shows, not what a note claims. If you are relying on a note, say "DayDream's note says...".
- Add the state when it matters: "sent", "send key used", "draft".
- When you quote the person's typed words, quote only the part the question needs, inside quotation marks, and cite where it was typed.
- Keep the ids for your own follow-up calls (`moment_details` with `id`). Don't show them.
- If two moments could be the one the person means, list both with citations and ask which one.
