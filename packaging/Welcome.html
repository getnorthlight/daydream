DayDream

Local activity memory for your Mac.

This installs DayDream, its command-line tool and its read-only MCP entry point. Recording stays off until you turn it on. The installer runs no scripts: it does not start recording, import history, request permissions, install a background service or send data anywhere.

After installation, open DayDream to set it up. Recording starts only when you choose to start it and grant the macOS permissions it asks for.
