# Bundled product icons

These local resources identify products and sites in DayDream. DayDream does
not request favicons from browsing history at runtime.

- `SiteIcons/cursor.png`: Cursor's default 2.5D dark app icon, scaled to 256 px
  from the official [Cursor brand kit](https://cursor.com/brand).
- `SiteIcons/claude-code.png`: Claude's official brand favicon from
  <https://claude.com/icon.png>, used for the Claude Code command-line product
  because it has no installed macOS app icon.
- `SiteIcons/google.png`: Google's official favicon from
  <https://www.google.com/favicon.ico>. Used only for google.com and
  www.google.com; other Google products keep their own site treatment.

Existing X and Instagram favicon resources remain bundled. Favicon bodies
use rounded corners on the app icon grid; browser badges remain separate.
